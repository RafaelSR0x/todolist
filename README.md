# To-Do List API

API REST para gerenciamento de tarefas, desenvolvida com Java e Spring Boot.

Este projeto está sendo desenvolvido com o objetivo de praticar e aprofundar conhecimentos em desenvolvimento backend, APIs REST, persistência de dados e boas práticas com Spring Boot.

## 🚀 Tecnologias

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- PostgreSQL
- Maven
- Git/GitHub

## 📌 Objetivo

Criar uma API para gerenciamento de tarefas, permitindo cadastrar, consultar, atualizar e excluir tarefas.

O projeto será desenvolvido de forma incremental, com novas funcionalidades sendo adicionadas conforme o aprendizado.

## 🔨 Funcionalidades
